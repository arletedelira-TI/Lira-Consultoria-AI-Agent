# Lira Consultoria AI Agent

Agente de INteligência Artificial especializado em Oracle Database, desenvolvido com RAG, LangChain, Hugging Face e ChromaDB.

## Objetivo

O projeto tem como objetivo desenvolver um agente capaz de responder oerguntas relacionadas a Oracle Database utilizando uma base de conhecimento documental.

### Tecnologias 

- Python
- LangChain
- HuggingFace
- ChromaDB
- Streamlit
- RAG
- Oracle Cloud
